# Online Quiz Application

A beginner-friendly multiple-choice quiz about HTML, CSS, and JavaScript. The project practices page structure, styling, JavaScript events, arrays, conditions, and score calculation.

## Features

- Multiple-choice questions
- Correct and incorrect answer feedback
- Previous and next navigation
- Score display and final result
- Restart button
- Responsive layout for smaller screens

## Built with

- HTML
- CSS
- JavaScript
- GitHub Pages for static hosting

## Run locally

Download or clone this repository, then open `index.html` in a web browser. No installation or server is required.

## Project files

- `index.html` - page structure and links to the styles and script
- `style.css` - layout, colors, and responsive styling
- `script.js` - quiz questions, navigation, feedback, and scoring

## Live demo

https://ananyaa31.github.io/online-quiz-application/

If the site has just been enabled, GitHub Pages may take a short time to publish it.

## Limitations

This is a frontend learning demo. It does not create user accounts or save scores to a server. Answers are stored only while the page is open.
